\chapter{Delete Relaxation Heuristic}\label{chap:heuristic}

In this section we define the integer linear program model $\mathit{ILP}(\mathcal{P}^+)$, which is the ILP formulation of a delete relaxed POCL planning problem $\mathcal{P}^+$. The goal of this ILP model is to ensure that a partial POCL plan $P$ is a relaxed POCL plan for $(\mathcal{P}^+)$ if and only if there is a corresponding feasible solution to $\mathit{ILP}(\mathcal{P}^+)$ whose cost is equivalent to the number of actions in $P$. This mapping will be injective, there may be more than one feasible solution corresponding to each relaxed POCL plan.

Firstly, we define the variables of $\mathit{ILP}(\mathcal{P}^+)$. Each solution of this ILP will represent a delete relaxed POCL plan, and we will call this plan $P$ to more simply explain the role of each variable in representing such a plan. Some of these variables are defined with an upper bound on solution length $\mathit{ub}$ which will be formally defined and proved later.\\

\textbf{Proposition Variables:} $UV=\{UV_{v,0} \in \{0,1\} \text{ for each } v\in V\}\cup\{UV_{v,ps} \in \{0,1\} \text{ for each } ps \in PS_I \text{ such that } v\in\Del(ps), \text{ for each } v\in V\}$. For each proposition $v$, we have a variable for its initial instance, and for each possible future instance after each deletion of $v$. Set to $1$ if and only if the proposition instance is achieved.\\
\textbf{Action Variables:} $UA=\{UA_{a,0,0} \in \{0,1\} \text{ for each } a\in A\}\cup\{UA_{a,v,ps} \in \{0,1\} \text{ for each } ps \in PS_I \text{ such that } v\in\Del(ps), \text{ for each } v\in \Add(a), \text{ for each } a\in A\}$. For each action $a$, we have a variable for its initial execution, and for each possible additional execution required to achieve its positive effect propositions. Set to $1$ if and only if the action instance is executed.\\
\textbf{Action Add Effect Variables:} $EA=\{EA_{a,v_a,0,0} \in \{0,1\} \text{ for each } v_a\in \Add(a), \text{ for each } a\in A\}\cup\{EA_{a,v_a,v_d,ps} \in \{0,1\} \text{ for each } ps \in PS_I \text{ such that } v\in\Del(ps), \text{ for each } v_a\in \Add(a), \text{ for each } v\in \Add(a), \text{ for each } a\in A\}$. We have a variable for each add effect $v_a\in \Add(a_{v_d,ps})$ of each instance $a_{v_d,ps}$ of an action $a$. Set to $1$ if and only if this action instance is the first achiever of an instance of $v_a$.\\
\textbf{Step Add Effect Variables:} $ES=\{ES_{ps,v} \in \{0,1\} \text{ for each } v\in \Add(ps), \text{ for each } ps \in PS_I$. We have a variable for each add effect $v\in \Add(ps)$ of each plan step $ps$. Set to $1$ if and only if this plan step is the first achiever of an instance of $v$.\\
\textbf{Proposition Time Variables:} $TV=\{TV_{v,0} \in \{0,\cdots,\mathit{ub}\} \text{ for each } v\in V\}\cup\{TV_{v,ps} \in \{0,\cdots,\mathit{ub}\} \text{ for each } ps \in PS_I \text{ such that } v\in\Del(ps), \text{ for each } v\in V\}$. For each proposition instance, its time variable is set to the time step that it is achieved. If it is not achieved then the time is not constrained.\\
\textbf{Action Time Variables:} $TA=\{TA_{a,0,0} \in \{0,\cdots,\mathit{ub}\} \text{ for each } a\in A\}\cup\{TA_{a,v,ps} \in \{0,\cdots,\mathit{ub}\} \text{ for each } ps \in PS_I \text{ such that } v\in\Del(ps), \text{ for each } v\in \Add(a), \text{ for each } a\in A\}$. For each action instance, its time variable is set to the time step that it is executed. If it is not executed then the time is not constrained.\\
\textbf{Step Time Variables:} $TS=\{TS_{ps} \in \{0,\cdots,\mathit{ub}\} \text{ for each } ps \in PS_I\}$. For each time step, its time variable is set to the time step that it is executed.\\

The objective function is defined as: \[\mathit{min}\left(|PS| + \sum UA\right)\]\\
