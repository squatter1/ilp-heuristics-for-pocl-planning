\chapter{Delete Relaxation Heuristic}\label{chap:heuristic}

In this section we define the ILP model $\mathit{ILP}(\mathcal{P}^+)$, which is the ILP formulation of a delete relaxed POCL planning problem $\mathcal{P}^+$. The goal of this ILP model is to ensure that there exists a relaxed POCL plan $P$ for $(\mathcal{P}^+)$ if and only if there is a corresponding feasible solution to $\mathit{ILP}(\mathcal{P}^+)$ whose cost is equivalent to the number of actions added to create $P$. This mapping will be injective, there may be more than one feasible solution corresponding to each relaxed POCL plan. Note that $\mathcal{P}^+$ represents a search node where current delete effects and causal links are not relaxed, future additional actions are delete-relaxed, and causal links are compiled to allow them to be respected by additional actions. This model is loosely based on the ILP model for a delete relaxed planning graph in classical planning by~\cite{Imai2015ILPDeleteRelaxedPlanning}.


\section{ILP Formulation of a Delete Relaxed POCL Problem}
We can now define the ILP model $\mathit{ILP}(\mathcal{P}^+)$, where $\mathcal{P}^+=(V, A, P_{s_I,g})$ and $P_{s_I,g}=(PS_I,\prec_I,CL_I)$. We will do this by first defining the variables, each of which will represent a member of $x$ in the optimal ILP instance, and then the objective function, which represents $c^Tx$, and finally the constraints, which represent $Ax\geq b$. After the formulation, we will prove the validity of the ILP model, and show how its formulation size grows as $(\mathcal{P}^+)$ grows.\\


The first step of transforming the input search node into an ILP problem is to remove the steps $\mathit{init}$ and $\mathit{goal}$ from $PS_I$, and also all orderings including either of those steps within $\prec_I$. This is because ILP variables relating to them will be added in separate sets, as they are handled differently. The model also often makes reference to $s_I$ and $g$ instead for simplicity. Note that since all causal links have already been compiled, the causal links connecting to these steps will still be respected.\\


Firstly, we define the variables of $\mathit{ILP}(\mathcal{P}^+)$. Each solution of this ILP will represent a delete-relaxed POCL plan, and we will call this plan $P$ to more simply explain the role of each variable in representing such a plan. Some of these variables are defined with an upper bound on solution length $\mathit{ub}$ which will be formally defined later. Each variable $v$ has a domain of allowable integer values $\mathit{dom}(v)$, which we . These are represented in the ILP problem by additional constraints.\\


\textbf{Proposition Usage Variables:} For each proposition $v$, we have a variable for its initial instance, and for each possible future instance after each deletion of $v$. These variables will have a value of $1$ if and only if the proposition instance is achieved.
\[PU=\{PU_{v,\mathit{init}} \mid v\in V\}\cup\{PU_{v,ps} \mid ps \in PS_I, v\in\Del(ps)\}\]
We also consider the subset of these variables which represent the initial state $s_I$.
\[PI=\{PU_{v,\mathit{init}} \mid v\in V,v\in s_I\}\]
These variables have two separate domains, as propositions in the initial state must be achieved.
\[\forall PU_{v,ps}\in PI: \mathit{dom}(PU_{v,ps})=\{1\}\]
\[\forall PU_{v,ps}\in PU\setminus PI: \mathit{dom}(PU_{v,ps})=\{0,1\}\]
\textbf{Action Usage Variables:} For each action $a$, we have one variable for its initial execution, and additional variables for each possible execution required to achieve its effect propositions after they are deleted. These variables will have a value of $1$ if and only if the action instance is executed.
\begin{align*}
AU&=\{AU_{a,\mathit{init},\mathit{init}} \mid a\in A\} \\
&\cup\{AU_{a,v,ps} \mid ps \in PS_I,a\in A,v\in\Del(ps)\cap \Add (a)\}
\end{align*}
\[\forall AU_{a,v,ps}\in AU: \mathit{dom}(AU_{a,v,ps})=\{0,1\}\]
\textbf{Action Effect Variables:} For each action usage variable $UA_{a,v,ps}$, we have a variable for each add effect of its associated action $a$. These variables will have a value of 1 if and only if the given action instance is a first achiever of the given effect.
\[AE=\{AE_{a_f,v_f,ps_f,v_a} \mid AU_{a_f,v_f,ps_f}\in AU, v_a\in \Add (a_f)\}\]
\[\forall AE_{a_f,v_f,ps_f,v_a}\in AE: \mathit{dom}(AE_{a_f,v_f,ps_f,v_a})=\{0,1\}\]
\textbf{Step Effect Variables:} For each plan step $ps$, we have a variable for each of its add effects. These variables will have a value of 1 if and only if the given plan step is a first achiever of the given effect.
\[SE=\{SE_{ps,v} \mid ps \in PS_I, v\in \Add(ps)\}\]
\[\forall SE_{ps,v}\in SE: \mathit{dom}(SE_{ps,v})=\{0,1\}\]
\textbf{Proposition Time Variables:} For each proposition usage variable $PU_{v,ps}$, we have a time variable. These variables will have a value of the execution time of  $PU_{v,ps}$ if  $PU_{v,ps}=1$, and are otherwise unconstrained.
\[PT=\{PT_{v,ps} \mid  PU_{v,ps}\in PU\}\]
\[\forall PT_{v,ps}\in PT: \mathit{dom}(PT_{v,ps})=\{0,\cdots,\mathit{ub}\}\]
\textbf{Action Time Variables:} For each action usage variable $AU_{a,v,ps}$, we have a time variable. These variables will have a value of the execution time of  $AU_{a,v,ps}$ if  $AU_{a,v,ps}=1$ (i.e. if this action instance is used in the plan), and are otherwise unconstrained.
\[AT=\{AT_{a,v,ps} \mid  AU_{a,v,ps}\in AU\}\]
\[\forall AT_{a,v,ps}\in AT: \mathit{dom}(AT_{a,v,ps})=\{0,\cdots,\mathit{ub}\}\]
\textbf{Step Time Variables:} For each plan step $ps$, we have a time variable. These variables will have the value of the execution time of $ps$.
\[ST=\{ST_{ps} \mid ps \in PS_I\}\]
\[\forall ST_{ps}\in ST: \mathit{dom}(ST_{ps})=\{0,\cdots,\mathit{ub}\}\]\\
We also define a set of step deletion constants which connect propositions to the steps which delete them. Note that these aren't ILP variables as their values can be determined directly from the input search node. They are used as constants within constraints.
\[SD=\{SD_{ps,v}\mid ps\in PS_I,v\in \Del (ps)\}\]
\[\forall SD_{ps,v}\in SD: \mathit{dom}(SD_{ps,v})=\{0,1\}\]\\
The objective function returns the minimum number of added actions required to complete the partial plan, and is defined as: \[\text{min }\sum_{AU_{a,v,ps}\in AU} AU_{a,v,ps}\]\\


Finally, we define the constraints of $\mathit{ILP}(\mathcal{P}^+)$. The value $M$ used in some of these constraints as a large value used to render constraints either necessarily true or necessarily false under some condition, and is set to $M=ub+2$. Note that a difference of one will cause issues with constraints that use a $+1$ to connect actions with effect propositions on the following time step. Additional variables will be described when necessary to represent the truth value of a linear inequality. For example a variable $v=(y-z\geq 0)$ would have a value of 1 when $y-z\geq 0$ and 0 otherwise. Fully notating these linear equality boolean variables requires multiple constraints to be added, but since the procedure to add these types of variables is well known, I will use the $v=(a^Tx\geq b)$ shorthand for simplicity. The operators $\vee$ and $\wedge$ will also be used as a shorthand, as it is well known how these operators can be encoded in an ILP.\\


\textbf{Goals Achieved (C1):} For each goal proposition, ensure that there is at least one instance achieved after all of its deletions.
\[\forall v_g\in g:\bigvee_{PU_{v_g,ps}\in PU}\left(PU_{v_g,ps_a}=1\wedge\left(\bigwedge_{SD_{ps_b,v_g}\in SD}(PT_{v_g,ps_a}-ST_{ps_b}\geq 1)\right)\right)\]
\textbf{First Achievers Must be Executed (C2):} For each action effect instance, ensure that if the action instance is the first achiever of this effect, the action instance is used.
\[ \forall AE_{a_i,v_i,ps_i,v_i}\in AE: AU_{a_i,v_i,ps_i}-AE_{a_i,v_i,ps_i,v_i}\geq 0\]
\textbf{Achievers Only Achieve False Propositions (C3):} For any pair of action/step effect variables corresponding to the same proposition, ensure there is at least one deletion of that proposition in-between them.\\
We first define sets representing action-action, action-step, and step-step pairs of effects. Note that these aren't ILP variables, but are defined because each element of these sets corresponds to one constraint.
\begin{align*}
AAP=\{&AAP_{a_f,v_f,ps_f,a_g,v_g,ps_g,v_a}\mid AE_{a_f,v_f,ps_f,v_a}\in AE,\\&AE_{a_g,v_g,ps_g,v_b}\in AE, v_a=v_b,(a_f,v_f,ps_f)\neq (a_g,v_g,ps_g)\}
\end{align*}
\begin{align*}
ASP=\{&ASP_{a_f,v_f,ps_f,ps_g,v_a}\mid AE_{a_f,v_f,ps_f,v_a}\in AE,SE_{ps_g,v_b}\in SE, v_a=v_b\}
\end{align*}
\begin{align*}
SSP=\{&SSP_{ps_f,ps_g,v_a}\mid SE_{ps_f,v_a}\in SE,SE_{ps_g,v_b}\in SE, v_a=v_b,ps_f\neq ps_g\}
\end{align*}
We can now utilise these variables to define the constraints. Duplicate inverse pairs in $AAP$ and $SSP$ are not explicitly excluded from this definition for simplicity, but are excluded in our implementation of this model:
\begin{align*}
    &\forall AAP_{a_f,v_f,ps_f,a_g,v_g,ps_g,v_a}\in AAP:\\&(AE_{a_f,v_f,ps_f,v_a}=0)\vee (AE_{a_g,v_g,ps_g,v_a}=0)\vee (AE_{a_f,v_f,ps_f,v_a}=0\\
    &\left(\bigvee_{SD_{ps_d,v_a}\in SD}(((AT_{a_f,v_f,ps_f}-ST_{ps_d}\geq 1)\wedge (ST_{ps_d}-AT_{a_g,v_g,ps_g}\geq 1))\right.\\
    &\hspace*{1.9cm}\vee ((AT_{a_g,v_g,ps_g}-ST_{ps_d}\geq 1)\wedge (ST_{ps_d}-AT_{a_f,v_f,ps_f}\geq 1)))\left.\vphantom{\bigvee_{x\in X}}\right)
\end{align*}
\begin{align*}
    &\forall ASP_{a_f,v_f,ps_f,ps_g,v_a}\in ASP:\\&(AE_{a_f,v_f,ps_f,v_a}=0)\vee (SE_{ps_g,v_a}=0)\vee\\
    &\left(\bigvee_{SD_{ps_d,v_a}\in SD}(((AT_{a_f,v_f,ps_f}-ST_{ps_d}\geq 1)\wedge (ST_{ps_d}-ST_{ps_g}\geq 1))\right.\\
    &\hspace*{1.9cm}\vee ((ST_{ps_g}-ST_{ps_d}\geq 1)\wedge (ST_{ps_d}-AT_{a_f,v_f,ps_f}\geq 1)))\left.\vphantom{\bigvee_{x\in X}}\right)
\end{align*}
\begin{align*}
    &\forall SSP_{ps_f,ps_g,v_a}\in SSP:\\&(SE_{ps_f,v_a}=0)\vee (SE_{ps_g,v_a}=0)\vee\\
    &\left(\bigvee_{SD_{ps_d,v_a}\in SD}(((ST_{ps_f}-ST_{ps_d}\geq 1)\wedge (ST_{ps_d}-ST_{ps_g}\geq 1))\right.\\
    &\hspace*{1.9cm}\vee ((ST_{ps_g}-ST_{ps_d}\geq 1)\wedge (ST_{ps_d}-ST_{ps_f}\geq 1))\left.\vphantom{\bigvee_{x\in X}}\right)
\end{align*}
Finally, we define constraints to ensure that initial propositions cannot be achieved by actions/steps before first being deleted.
\begin{align*}
    &\forall v_i\in s_I, \forall AE_{a_f,v_f,ps_f,v_i}\in AE:(AE_{a_f,v_f,ps_f,v_i}=0)\vee\\
    &\left(\bigvee_{SD_{ps_d,v_i}\in SD}(AT_{a_f,v_f,ps_f}-ST_{ps_d}\geq 1)\right)
\end{align*}
\begin{align*}
    &\forall v_i\in s_I, \forall SE_{ps_f,v_i}\in SE:(SE_{ps_f,v_i}=0)\vee\\
    &\left(\bigvee_{SD_{ps_d,v_i}\in SD}(ST_{ps_f}-ST_{ps_d}\geq 1)\right)
\end{align*}
\textbf{Propositions are Preceded by an Achiever (C4):} For each proposition instance that is not in $s_I$, ensure that prior to the instance being achieved, the number of actions/steps achieving the proposition exceed the number of other instances of the proposition which are achieved. This requires defining three sets of additional linear equality boolean variables.\\
Firstly, we define a set of action effect achieved variables representing whether a given action effect achieves the proposition prior to the proposition time of the instance.
\[AEA=\{AEA_{v_i,ps_i,a_f,v_f,ps_f,v_a}\in\{0,1\}\mid PU_{v_i,ps_i}\in PU,AE_{a_f,v_f,ps_f,v_a}\in AE\}\]
\[ \forall AEA_{v_i,ps_i,a_f,v_f,ps_f,v_a}\in AEA:AEA_{v_i,ps_i,a_f,v_f,ps_f,v_a}=(PT_{v_i,ps_i}-AT_{a_f,v_f,ps_f}\geq 1)\]
Next, we define a set of step effect achieved variables representing whether a given step effect achieves the proposition prior to the proposition time of the instance.
\[SEA=\{SEA_{v_i,ps_i,ps_j,v_j}\in\{0,1\}\mid PU_{v_i,ps_i}\in PU,SE_{ps_j,v_j}\in SE\}\]
\[ \forall SEA_{v_i,ps_i,ps_j,v_j}\in SEA:SEA_{v_i,ps_i,ps_j,v_j}=(PT_{v_i,ps_i}-ST_{ps_j}\geq 1)\]
Finally, we define a set of proposition instance achieved variables representing whether a given other instance of the proposition is achieved before the proposition time of the instance.
\[PIA=\{PIA_{v,ps_i,ps_j}\in\{0,1\}\mid PU_{v,ps_i}\in PU,PU_{v,ps_j}\in PU,ps_i\neq ps_j\}\]
\[ \forall PIA_{v,ps_i,ps_j}\in PIA:PIA_{v,ps_i,ps_j}=(PT_{v,ps_i}-PT_{v,ps_j}\geq 0)\]
By utilising these variables we can now define the constraints:
\begin{align*}
\forall PU_{v_i,ps_i}\in PU\setminus SI:&\sum_{AEA_{v_i,ps_i,a_f,v_f,ps_f,v_a}\in AEA}(AE_{a_f,v_f,ps_f,v_a}AEA_{v_i,ps_i,a_f,v_f,ps_f,v_a})\\&+\sum_{SEA_{v_i,ps_i,ps_j,v_j}\in SEA}(SE_{ps_j,v_j}SEA_{v_i,ps_i,ps_j,v_j})\\&-\sum_{PIA_{v_i,ps_i,ps_j}\in PIA}PIA_{v_i,ps_i,ps_j}+M(1-PU_{v_i,ps_i})\geq 1
\end{align*}
\textbf{Actions are Preceded by their Preconditions (C5):} For each action instance, and each of its preconditions, ensure that prior to the action being executed the number of instances of the precondition achieved exceed the number of steps which delete the precondition executed. This requires defining two sets of additional linear equality boolean variables.\\
Firstly, we define a set of action precondition satisfied variables representing whether a precondition instance is achieved prior to the action:
\[APS=\{APS_{a_i,v_i,ps_i,v_j,ps_j}\in\{0,1\}\mid AU_{a_i,v_i,ps_i}\in AU, v_j\in\Pre (a_i), PU_{v_j,ps_j}\in PU\}\]
\[\forall APS_{a_i,v_i,ps_i,v_j,ps_j}\in APS: APS_{a_i,v_i,ps_i,v_j,ps_j}=(PT_{v_j,ps_j}-AT_{a_i,v_i,ps_i}\geq 0)\]
We also define a set of action precondition deleted variables representing whether the precondition is deleted by a given step prior to the action:
\[APD=\{APD_{a_i,v_i,ps_i,ps_j}\in\{0,1\}\mid AU_{a_i,v_i,ps_i}\in AU, ps_j\in PS_I\}\]
\[\forall APD_{a_i,v_i,ps_i,ps_j}\in APD: APD_{a_i,v_i,ps_i,ps_j}=(AT_{a_i,v_i,ps_i}-ST_{ps_j}\geq 1)\]
By utilising these variables we can now define the constraints:
\begin{align*}
\forall AU_{a_i,v_i,ps_i}\in AU, \forall v_p\in\Pre (a_i):& \sum_{PU_{v_p,ps_j}\in PU}(PU_{v_p,ps_j}APS_{a_i,v_i,ps_i,v_p,ps_j})\\&-\sum_{ps_j\in PS_I}APD_{a_i,v_i,ps_i,ps_j}+M(1-AU_{a_i,v_i,ps_i})\geq 1
\end{align*}
\textbf{Steps are Preceded by their Preconditions (C6):} For each plan step, and each of its preconditions, ensure that prior to the plan step being executed the number of instances of the precondition achieved exceed the number of other steps which delete the precondition executed. This requires defining two sets of additional linear equality boolean variables.\\
Firstly, we define a set of step precondition satisfied variables representing whether a precondition instance is achieved prior to the step:
\[SPS=\{SPS_{ps_i,v_j,ps_j}\in\{0,1\}\mid ps_i\in PS_I, v_j\in\Pre (ps_i), PU_{v_j,ps_j}\in PU\}\]
\[\forall SPS_{ps_i,v_j,ps_j}\in SPS: SPS_{ps_i,v_j,ps_j}=(PT_{v_j,ps_j}-ST_{ps_i}\geq 0)\]
We also define a set of step precondition deleted variables representing whether the precondition is deleted by a given other step prior to the step:
\[SPD=\{SPD_{ps_i,ps_j}\in\{0,1\}\mid ps_i\in PS_I, ps_j\in PS_I\}\]
\[\forall SPD_{ps_i,ps_j}\in SPD: SPD_{ps_i,ps_j}=(ST_{ps_i}-ST_{ps_j}\geq 1)\]
By utilising these variables we can now define the constraints:
\[ \forall ps_i\in PS_I, \forall v_p\in\Pre (ps_i): \sum_{PU_{v_p,ps_j}\in PU}(PU_{v_p,ps_j}SPS_{ps_i,v_p,ps_j})-\sum_{ps_j\in PS_I}SPD_{ps_i,ps_j}\geq 1\]
\textbf{Step Interference (C7):} For each pair of steps $(ps_i,ps_j)$ where one deletes a precondition of the other, ensure they cannot execute in parallel.\\
We first define the set of interfering step pairs which require a constraint:
\[SI=\{SI_{ps_i,ps_j}\mid ps_i\in PS_I, ps_j\in PS_I, \Del (ps_i)\cap \Pre (ps_j)\neq \emptyset \vee \Pre (ps_i)\cap \Del (ps_j)\neq \emptyset\}\]
Then we define the corresponding constraints:
\[ \forall SI_{ps_i,ps_j}\in SI:ST_{ps_i}\neq ST_{ps_j}\]
\textbf{Step Orderings (C8):} For each step ordering in $\prec _I$, we enforce that this ordering holds.
\[ \forall( ps_i\prec ps_j)\in\,\prec_I: ST_{ps_j}-ST_{ps_i}\geq 1\]
Note that these constraints necessitate that each achieved proposition instance has only one achiever in any feasible solution.

For any feasible solution to an ILP problem $\mathit{ILP}(\mathcal{P}^+)$, the following implicit constraint must be satisfied:
\[\forall PU_{v,ps}\in PU:\sum_{AE_{a_i,v_i,ps_i,v}\in AE}AE_{a_i,v_i,ps_i,v}\leq 1\]
\end{prop}

We now prove that for any solution to a delete-relaxed POCL planning problem $\mathcal{P}^+$, the corresponding instance of $\mathit{ILP}(\mathcal{P}^+)$ will be feasible solution.
\begin{thm}
Given a delete-relaxed POCL planning problem $\mathcal{P}^+$, a POCL solution $P$ for $\mathcal{P}^+$, and the action sequence $\overline{a}$ of any linearization of $P$, there is a corresponding feasible solution to $\mathit{ILP}(\mathcal{P}^+)$.
\end{thm}
\textit{Proof.} For $P=(PS,\prec , CL)$ to be a POCL solution all of its linearizations must be total-order solutions. Hence, $\overline{a}$ must result in a goal state, of which $g$ must be a subset. For this to be true, each $v_g\in g$ must be at some point achieved after all of its deletions. This means that one $PU$ variable corresponding to $v_g$ must be achieved after all steps which delete $v_g$ are executed, and so its corresponding $PT$ variable must be after all deleting $ST$ variables. Thus, constraint C1 must be satisfied.\\
Constraint C2 is satisfied as for any action in $\overline{a}$ to achieve its effect and hence have its $AE$ variable set to 1, it also has to be executed and so have its $AU$ variable set to 1.\\
For constraint C3, by definition we only set $AE$ and $SE$ variables when the effects are achieved, and hence were previously false. This means that for each pair of effect variables which are set to 1 and act on the same proposition, there must be a step in-between them which deletes the proposition, so that it is able to be achieved again. Hence, there must be at least one deleting step such that either the first achieving action is executed before the deleting step which is executed before the second achieving action, or vice versa. Additionally, initial propositions must be deleted before they can be achieved at all, and so for each effect variable set to 1 for an initial proposition, there must be at least one deleting step prior to the achieving action/step. Thus, constraint C3 holds.\\
Each of these achievers will set an instance of the achieved proposition to true at the next time step, and only initial propositions don't have a corresponding achiever. So $AE/SE$ variables which are set to 1 are paired with $PU$ variables set to 1, where $AT/ST + 1 = PT$. Hence, for any $PU$ variable set to 1, the number of other instances of the same proposition with times the same of beforehand, minus the number of achievers beforehand, will always be 1. Thus, constraint C4 holds.\\
Because $P$ is a POCL solution, every precondition must be supported by a causal link. This causal link prevents threats by requiring that all steps which could potentially delete that precondition to either be ordered before the producer step or after the consumer step. Translating this to the ILP model, each precondition requires at least one instance where all deleting steps are either ordered before the instance is achieved or after the action/step the precondition is used for. This matches with constraints C5 and C6, ensuring that they are satisfied.\\
Constraint C7 is trivial for a total-order action sequence, as all steps run at a unique time, and so any time inequality constraint between steps will be satisfied.\\
Finally, constraint C8 also trivially holds, as step orderings in $\prec$ are required to hold for any linearization of $P$, and so they will also hold in the corresponding ILP problem.\\
