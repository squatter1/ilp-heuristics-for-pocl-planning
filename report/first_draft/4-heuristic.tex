\chapter{Delete Relaxation Heuristic}\label{chap:heuristic}

In this section we define the ILP model $\mathit{ILP}(\mathcal{P}^+)$, which is the ILP formulation of a delete relaxed POCL planning problem $\mathcal{P}^+$. The goal of this ILP model is to ensure that there exists a relaxed POCL plan $P$ for $(\mathcal{P}^+)$ if and only if there is a corresponding feasible solution to $\mathit{ILP}(\mathcal{P}^+)$ whose cost is equivalent to the number of actions added to create $P$. This mapping will be injective, there may be more than one feasible solution corresponding to each relaxed POCL plan. Note that $\mathcal{P}^+$ represents a search node where current delete effects and causal links are not relaxed, future additional actions are delete-relaxed, and causal links are compiled to allow them to be respected by additional actions. Due to this compilation, causal links are represented as propositions, and will not be treated differently to any other proposition in the model. This model is loosely based on the ILP model for a delete relaxed planning graph in classical planning by~\cite{Imai2015ILPDeleteRelaxedPlanning}.\\


We now define the ILP model $\mathit{ILP}(\mathcal{P}^+)$, where $\mathcal{P}^+=(V, A, P_{s_I,g})$ and $P_{s_I,g}=(PS_I,\prec_I,CL_I)$. We will do this by first defining the variables, each of which will represent a member of $x$ in the optimal ILP instance, and then the objective function, which represents $c^Tx$, and finally the constraints, which represent $Ax\geq b$. After the formulation, we will prove the validity of the ILP model.\\


The first step of transforming the input search node into an ILP problem is to remove the steps $\mathit{init}$ and $\mathit{goal}$ from $PS_I$, and also all orderings including either of those steps within $\prec_I$. This is because ILP variables relating to them will be added in separate sets, as they are handled differently. The model also often makes reference to $s_I$ and $g$ instead for simplicity. Note that since all causal links have already been compiled, the causal links connecting to these steps will still be respected.\\


Firstly, we define the variables of $\mathit{ILP}(\mathcal{P}^+)$. Each variable $v$ has a domain of allowable integer values $\mathit{dom}(v)$. Some variable domains include an upper bound $\mathit{ub}$, which is an upper bound on the number of actions and steps in the solution plan. For the initial search node, which contains no plan steps other than $\mathit{init}$ and $\mathit{goal}$, the length of the planning graph is used as an upper bound. Successive search nodes use an upper bound derived from the solution length of their parent. With a single refinement, the solution length of a search node on a valid branch can only increase by the number of new delete effects added in the refinement, and so this informs the bounds of child search nodes.\\


\textbf{Proposition Usage Variables:} For each proposition $v$, we have a variable for its initial instance, and for each possible future instance after each deletion of $v$. These variables will have a value of $1$ if and only if the proposition instance is achieved.
\[PU=\{PU_{v,\mathit{init}} \mid v\in V\}\cup\{PU_{v,ps} \mid ps \in PS_I, v\in\Del(ps)\}\]
We also consider the subset of these variables which represent the initial state $s_I$.
\[PI=\{PU_{v,\mathit{init}} \mid v\in V,v\in s_I\}\]
These variables have two separate domains, as propositions in the initial state must be achieved.
\[\forall PU_{v,ps}\in PI: \mathit{dom}(PU_{v,ps})=\{1\}\]
\[\forall PU_{v,ps}\in PU\setminus PI: \mathit{dom}(PU_{v,ps})=\{0,1\}\]
\textbf{Action Usage Variables:} For each action $a$, we have one variable for its initial execution, and additional variables for each possible execution required to achieve its effect propositions after they are deleted. These variables will have a value of $1$ if and only if the action instance is executed.
\begin{align*}
AU&=\{AU_{a,\mathit{init},\mathit{init}} \mid a\in A\} \\
&\cup\{AU_{a,v,ps} \mid ps \in PS_I,a\in A,v\in\Del(ps)\cap \Add (a)\}
\end{align*}
\[\forall AU_{a,v,ps}\in AU: \mathit{dom}(AU_{a,v,ps})=\{0,1\}\]
\textbf{Action Effect Variables:} For each action usage variable $UA_{a,v,ps}$, we have a variable for each add effect of its associated action $a$. These variables will have a value of 1 if and only if the given action instance is executed and is a first achiever of the given effect.
\[AE=\{AE_{a_f,v_f,ps_f,v_a} \mid AU_{a_f,v_f,ps_f}\in AU, v_a\in \Add (a_f)\}\]
\[\forall AE_{a_f,v_f,ps_f,v_a}\in AE: \mathit{dom}(AE_{a_f,v_f,ps_f,v_a})=\{0,1\}\]
\textbf{Step Effect Variables:} For each plan step $ps$, we have a variable for each of its add effects. These variables will have a value of 1 if and only if the given plan step is a first achiever of the given effect.
\[SE=\{SE_{ps,v} \mid ps \in PS_I, v\in \Add(ps)\}\]
\[\forall SE_{ps,v}\in SE: \mathit{dom}(SE_{ps,v})=\{0,1\}\]
\textbf{Proposition Time Variables:} For each proposition usage variable $PU_{v,ps}$, we have a time variable. These variables will have a value of the execution time of  $PU_{v,ps}$ if  $PU_{v,ps}=1$, and are otherwise unconstrained.
\[PT=\{PT_{v,ps} \mid  PU_{v,ps}\in PU\}\]
\[\forall PT_{v,ps}\in PT: \mathit{dom}(PT_{v,ps})=\{0,\cdots,\mathit{ub}\}\]
\textbf{Action Time Variables:} For each action usage variable $AU_{a,v,ps}$, we have a time variable. These variables will have a value of the execution time of $AU_{a,v,ps}$ if $AU_{a,v,ps}=1$ (i.e. if this action instance is used in the plan), and are otherwise unconstrained.
\[AT=\{AT_{a,v,ps} \mid  AU_{a,v,ps}\in AU\}\]
\[\forall AT_{a,v,ps}\in AT: \mathit{dom}(AT_{a,v,ps})=\{0,\cdots,\mathit{ub}\}\]
\textbf{Step Time Variables:} For each plan step $ps$, we have a time variable. These variables will have the value of the execution time of $ps$.
\[ST=\{ST_{ps} \mid ps \in PS_I\}\]
\[\forall ST_{ps}\in ST: \mathit{dom}(ST_{ps})=\{0,\cdots,\mathit{ub}\}\]\\
We also define a set of step deletion constants which connect propositions to the steps which delete them. Note that these aren't ILP variables as their values can be determined directly from the input search node. They are used as constants within constraints.
\[SD=\{SD_{ps,v}\mid ps\in PS_I,v\in \Del (ps)\}\]
\[\forall SD_{ps,v}\in SD: \mathit{dom}(SD_{ps,v})=\{0,1\}\]\\
The objective function returns the minimum number of added actions required to complete the partial plan, and is defined as: \[\text{min }\sum_{AU_{a,v,ps}\in AU} AU_{a,v,ps}\]\\


Finally, we define the constraints of $\mathit{ILP}(\mathcal{P}^+)$. The value $M$ used in some of these constraints as a large value used to render constraints either necessarily true or necessarily false under some condition, and is set to $M=ub+2$. Note that a difference of one will cause issues with constraints that involve a difference of 1 when connecting actions with effect propositions on the following time step. The operators $\vee$ and $\wedge$ will be used as a shorthand within constraints, as it is well known how these operators can be encoded in an ILP.\\


\textbf{Goals Achieved (C1):} For each goal proposition, ensure that there is at least one instance achieved after all of its deletions.
\[\forall v_g\in g:\bigvee_{PU_{v_g,ps_a}\in PU}\left(PU_{v_g,ps_a}=1\wedge\left(\bigwedge_{SD_{ps_b,v_g}\in SD}(PT_{v_g,ps_a}-ST_{ps_b}\geq 1)\right)\right)\]
\textbf{First Achievers Must be Executed (C2):} For each action effect instance, ensure that if the action instance is the first achiever of this effect, the action instance is used.
\[ \forall AE_{a_i,v_i,ps_i,v_i}\in AE: AU_{a_i,v_i,ps_i}-AE_{a_i,v_i,ps_i,v_i}\geq 0\]
\textbf{Propositions are Preceded by an Achiever (C3):} For each proposition instance that is not in $s_I$, ensure that the time step prior to the instance being achieved contains an achiever for the proposition.\\
\begin{align*}
&\forall PU_{v_i,ps_i}\in PU\setminus SI:\\
&PU_{v_i,ps_i}=0\vee\\
&\bigvee_{AE_{a_f,v_f,ps_f,v_i}\in AE}((AE_{a_f,v_f,ps_f,v_i}=1)\wedge (PT_{v_i,ps_i}-AT_{a_f,v_f,ps_f}=1))\\
&\bigvee_{SE_{ps,v_i}\in SE}((SE_{ps,v_i}=1)\wedge (PT_{v_i,ps_i}-ST_{ps}=1))
\end{align*}
\textbf{Actions are Preceded by their Preconditions (C4):} For each action instance, and each of its preconditions, ensure that there is at least one instance of the precondition achieved before the action instance, and no deletions of the precondition in-between the times of the precondition instance and the action instance.\\
\begin{align*}
&\forall AU_{a_i,v_i,ps_i}\in AU, \forall v_p\in\Pre (a_i):\\
&AU_{a_i,v_i,ps_i}=0\vee\bigvee_{PU_{v_p,ps_a}\in PU}\left(\vphantom{\bigwedge_{SD_{ps_b,v_p}\in SD}}(PU_{v_p,ps_a}=1)\wedge (AT_{a_i,v_i,ps_i}-PT_{v_p,ps_a}\geq 0)\wedge\right.\\
&\left(\bigwedge_{SD_{ps_b,v_p}\in SD}((PT_{v_p,ps_a}-ST_{ps_b}\geq 1)\vee(ST_{ps_b}-AT_{a_i,v_i,ps_i}\geq 1))\right)\left.\vphantom{\bigwedge_{SD_{ps_b,v_p}\in SD}}\right)
\end{align*}
\textbf{Steps are Preceded by their Preconditions (C5):} For each plan step instance, and each of its preconditions, ensure that there is at least one instance of the precondition achieved before the plan step, and no deletions of the precondition in-between the times of the precondition instance and the plan step.\\
\begin{align*}
&\forall ps_i\in PS, \forall v_p\in\Pre (ps_i):\\
&\bigvee_{PU_{v_p,ps_a}\in PU}\left(\vphantom{\bigwedge_{SD_{ps_b,v_p}\in SD}}(PU_{v_p,ps_a}=1)\wedge (ST_{ps_i}-PT_{v_p,ps_a}\geq 0)\wedge\right.\\
&\left(\bigwedge_{SD_{ps_b,v_p}\in SD}((PT_{v_p,ps_a}-ST_{ps_b}\geq 1)\vee(ST_{ps_b}-ST_{ps_i}\geq 1))\right)\left.\vphantom{\bigwedge_{SD_{ps_b,v_p}\in SD}}\right)
\end{align*}
\textbf{Step Interference (C6):} For each pair of steps $(ps_i,ps_j)$ where one deletes a precondition of the other, ensure they cannot execute in parallel.\\
We first define the set of interfering step pairs which require a constraint:
\[SI=\{SI_{ps_i,ps_j}\mid ps_i\in PS_I, ps_j\in PS_I, \Del (ps_i)\cap \Pre (ps_j)\neq \emptyset \vee \Pre (ps_i)\cap \Del (ps_j)\neq \emptyset\}\]
Then we define the corresponding constraints:
\[ \forall SI_{ps_i,ps_j}\in SI:ST_{ps_i}\neq ST_{ps_j}\]
\textbf{Step Inconsistent Effects (C7):} For each pair of steps $(ps_i,ps_j)$ where an add effect of one step is a delete effect of the other, ensure they cannot execute in parallel.\\
We first define the set of inconsistent step pairs which require a constraint:
\[SIE=\{SIE_{ps_i,ps_j}\mid ps_i\in PS_I, ps_j\in PS_I, \Del (ps_i)\cap \Add (ps_j)\neq \emptyset \vee \Add (ps_i)\cap \Del (ps_j)\neq \emptyset\}\]
Then we define the corresponding constraints:
\[ \forall SIE_{ps_i,ps_j}\in SIE:ST_{ps_i}\neq ST_{ps_j}\]
\textbf{Step Orderings (C8):} For each step ordering in $\prec _I$, we enforce that this ordering holds.
\[ \forall( ps_i\prec ps_j)\in\,\prec_I: ST_{ps_j}-ST_{ps_i}\geq 1\]


We now prove that for any solution to a delete-relaxed POCL planning problem $\mathcal{P}^+$, the corresponding instance of $\mathit{ILP}(\mathcal{P}^+)$ will be feasible solution.
\begin{thm}
Given a delete-relaxed POCL planning problem $\mathcal{P}^+$, a POCL solution $P$ for $\mathcal{P}^+$, and the action sequence $\overline{a}$ of any linearization of $P$, there is a corresponding feasible solution to $\mathit{ILP}(\mathcal{P}^+)$.
\end{thm}
\textit{Proof.} For $P=(PS,\prec , CL)$ to be a POCL solution all of its linearizations must be total-order solutions. Hence, $\overline{a}$ must result in a goal state, of which $g$ must be a subset. For this to be true, each $v_g\in g$ must be at some point achieved after all of its deletions. This means that one $PU$ variable corresponding to $v_g$ must be achieved after all steps which delete $v_g$ are executed, and so its corresponding $PT$ variable must be after all deleting $ST$ variables. Thus, constraint C1 must be satisfied.\\
Constraint C2 is satisfied as for any action in $\overline{a}$ to achieve its effect and hence have its $AE$ variable set to 1, it also has to be executed and so have its $AU$ variable set to 1.\\
Each achiever will set an instance of the achieved proposition to true at the next time step, and only initial propositions don't have a corresponding achiever. So $AE/SE$ variables which are set to 1 are paired with $PU$ variables set to 1, where $AT/ST + 1 = PT$. Thus, constraint C3 holds.\\
Because $P$ is a POCL solution, every precondition must be supported by a causal link. This causal link prevents threats by requiring that all steps which could potentially delete that precondition to either be ordered before the producer step or after the consumer step. Translating this to the ILP model, each precondition requires at least one instance where all deleting steps are either ordered before the instance is achieved or after the action/step the precondition is used for. This matches with constraints C4 and C5, ensuring that they are satisfied.\\
Constraints C6 and C7 are trivial for a total-order action sequence, as all steps run at a unique time, and so any time inequality constraint between steps will be satisfied.\\
Finally, constraint C8 also holds, as step orderings in $\prec$ are required to hold for any linearization of $P$, and so they will also hold in the corresponding ILP problem.
\begin{thm}
Given a feasible solution for $\mathit{ILP}(\mathcal{P}^+)$, the plan step sequence $\overline{ps}$ obtained by ordering all action instances $\{a\mid AU_{a,v,ps}=1\}$ (converted to plan steps with labels $(a,v,ps)$) and steps $ps\in PS$ by ascending order of their respective time variables $AT$ and $ST$ (with ties broken randomly), is a valid linearization of a POCL solution $P$ for $\mathcal{P}^+$.
\end{thm}
\textit{Proof.} We must show that such a plan $P=(V,A,P_{s_I,g})$ satisfies the requirements that every precondition is supported by a causal link, and all causal threats are resolved. To do this, we first construct $P=(PS,\prec,CL)$. Firstly, we set $PS$ to the set of all plan steps in $\overline{ps}$, as well as the $\mathit{init}$ and $\mathit{goal}$ steps, constructed from $s_I$ and $g$. In addition to the necessary $\mathit{init}$ and $\mathit{goal}$ orderings, we add orderings to $\prec$ for all orderings within $\overline{ps}$. I.e. for each $ps_i$ in the sequence $\overline{ps}$, all steps $ps_j$ where $j<i$ add an ordering $(ps_j,ps_i)$ to $\prec$, and all steps $ps_j$ where $i>j$ add an ordering $(ps_i,ps_j)$ to $\prec$. Finally, for each precondition $ps_c\in PS,v\in\Pre(ps_c)$, a causal link $ps_p,v,ps_c$ is added to $CL$, where $ps_c$ corresponds to the plan step prior to and closest to $ps_c$ in $\overline{ps}$ which has an action/step effect variable for $v$ in the ILP solution equal to 1. I.e. $ps_c$ is the closest achiever of $v$ prior to $ps_p$. If no such achiever exists then $ps_p=\mathit{init}$. Because $\overline{ps}$ contains all plan steps from $P$ and follows all orderings in $\prec$, it is a valid linearization of $P$. \\
Now that $P$ is constructed, we first show that all preconditions are supported by a causal link. Since it has been shown how all required causal links are constructed from a given $ps_c$ and $v$, we only need to prove that the producer steps are valid, i.e. $\forall (ps_p,v,ps_c)\in CL: v\in\Add(ps_p)$. Since $ps_p$ corresponds to a $AE$ or $SE$ variable for $v$, and these variables only exist when $v$ is an add effect for the action/step of the variable, when such a variable exists the causal link will always be valid. When there is no such variable, $ps_p=\mathit{init}$, and so we must prove that $v\in s_I$. From constraint C3, we know that if a proposition instance has no corresponding $AE$ or $SE$ variables set to 1, the constraint can only be satisfied if the proposition instance is never achieved, or the proposition instance is from the initial state (in which case no C3 constraint is created, and so C3 trivially holds). We know from constraints C4 and C5 (or C1 if $ps_c=\mathit{goal}$) that since $v\in\Pre(ps_c)$, and $ps_c$ is executed and hence its $AU$ variable is set to 1 if it has one, that at least one instance of $v$ must be achieved (to meet the $(PU_{v_p,ps_a}=1)$ part of the constraint). Hence, that instance must be in the initial state, and so $v\in s_I$ holds. Thus, all preconditions in $P$ are supported by a causal link.\\
The second and final requirement is that all causal threats in $P$ are resolved. This requires that for all causal links, potentially threatening steps are ordered before the producer step or after the consumer step, i.e. $\forall (ps_p,v,ps_c)\in CL,ps_t\in PS: v\in\Del(ps_t)\implies ((ps_t,ps_p)\in\prec\vee(ps_c,ps_t)\in\prec)$. Assume for a contradiction that such a $ps_t$ exists which is ordered in-between $ps_p$ and $ps_c$. Constraint C6 ensures that $ps_t$ can't be ordered directly before $ps_c$ in $\overline{ps}$ by running in parallel with $ps_c$, as they would necessarily interfere. Constraint C7 ensures that $ps_t$ can't be ordered directly after $ps_p$ in $\overline{ps}$ by running in parallel with $ps_p$, as they would necessarily have inconsistent effects. Hence, $ps_t$ must already be ordered in-between $ps_p$ and $ps_c$ before ties are broken. From constraints C4 and C5, since $ps_t$ and $ps_c$ cannot run in parallel, there must be at least one instance of $v$ which is ordered after $ps_t$ and before $ps_c$. However, $ps_p$ has been defined as the last achiever of $v$ before $ps_c$, and so for constraint C3 to hold, any instance of $v$ which is timed before $ps_c$ must also be before $ps_t$, creating a contradiction. Therefore, $\forall (ps_p,v,ps_c)\in CL,ps_t\in PS: v\in\Del(ps_t)\implies ((ps_t,ps_p)\in\prec\vee(ps_c,ps_t)\in\prec)$, and so all causal threats in $P$ are resolved.
\begin{cor}
Given an optimal solution for $\mathit{ILP}(\mathcal{P}^+)$, the plan step sequence $\overline{ps}$ obtained by ordering all action instances $\{a\mid AU_{a,v,ps}=1\}$ (converted to plan steps with labels $(a,v,ps)$) and steps $ps\in PS$ by ascending order of their respective time variables $AT$ and $ST$ (with ties broken randomly), is a valid linearization of a POCL solution $P$ for $\mathcal{P}^+$ with a minimum number of plan steps.
\end{cor}
