\chapter{Introduction}\label{chap:introduction}

Partial Order Causal Link (POCL) planning is a subclass of planning that maintains a principle of least commitment~\cite{An Introduction to Least Commitment Planning.}. While classical planning approaches search the space of states, which involves committing to an ordered sequence of actions which reaches that state, POCL planning searches the space of partial plans, where actions only have a partial set of ordering constraints. This means that a single partial plan can represent up to a factorial number of action sequences, and hence POCL search trees can be exponentially smaller than their total-order counterparts, a reasoning used to justify the intuitive superiority of partial-order planning until the mid 90s~\cite{Total-Order and Partial-Order Planning: A Comparative Analysis}. It was found that `the superiority of partial-order planning \textit{can} depend critically upon the search strategy and search heuristics employed'~\cite{Total-Order and Partial-Order Planning: A Comparative Analysis}. Total-order state based planning allows for intuitive, easy to compute, and powerful heuristics and search strategies, whereas partial-order planning struggled to generate any comparable heuristics. The turning point of this realisation was UNPOP, a state-based solver by~\cite{A Heuristic Estimator for Means Ends Analysis in Planning.} which automatically generated domain-independent heuristics that allowed state-based planners to solve problems orders of magnitude faster than the partial-order planners of the time. Today, state-based planning is still the dominant technique, but despite attempts to theoretically prove that partial-order planning is fundamentally less efficient than other planning methods, for example by~\cite{All PSPACE-Complete Planning Problems Are Equal but Some Are More Equal than Others}, these attempts have failed. Instead, it is possible that heuristic efficiency, and the growth of other parts of the search tree not explicitly included in the input size when calculating computational complexity, could be at fault for the current poor performance of partial-order planners, as is the case for heuristic search algorithms over implicit graphs in general as shown by~\cite{The complexity of searching implicit graphs}. Hence, when considering the performance of partial-order planning, it is critical to consider the implicit input size, for example the complexity of the node fed to a heuristic algorithm, and how that affects heuristic performance.\\


The input for heuristics in partial-order planning is more complex than state-based planning. In state-based planning, the current search progress can be fed to a heuristic algorithm as a finite list of variables and their values. In POCL planning, this search progress contains a list of steps, which can contain repeated actions and hence has an unbounded length, a set of orderings between those steps, which can be even larger, and a set of causal links between effects and preconditions of these steps, which can be larger still. In addition, the size of each search node grows with search depth in POCL planning as more steps, orderings, and causal links are added, whereas it remains constant in state-based planning. This problem has been recognised when creating heuristics for partial-order planning, and the two major well-informed domain-independent heuristics for POCL planning, the \textit{Relax heuristic} created by~\cite{Reviving Partial Order Planning}, and the \textit{Additive heuristic} created by ~\cite{VHPOP: Versatile Heuristic Partial Order Planner}, solve it by not including much of the partial-plan information in the input to their heuristics. The additive heuristic ignores causal links and delete effects of actions within the current partial-plan, and the relax heuristic additionally ignores ordering constraints between actions. This reduction of search node components to consider when generating heuristic estimates allows both of these heuristics to run in polytime.\\


The recognition of heuristic input complexity having a significant effect on planning efficiency causes a major issue in POCL planning. While the technique of ignoring vast amounts of partial-plan information when calculating heuristics has led to the creation of informed heuristics that are very fast to compute, such as the Relax and Additive heuristics, these heuristics are significantly less informed than if they accounted for all of the information within the partial-plan they are calculated on. Causal links in particular contain a large amount of information, as they commit to causal relationships between actions, specifying that an effect of one action is required to protect the precondition of a later action, preventing actions that delete the linked proposition from being inserted between the two linked actions. This induces a constraint on where actions can be included within a plan, and hence essentially prunes a large number of possible action sequences. The delete effects of actions within a partial plan also have a pruning effect, as they delete propositions which could have otherwise been used as preconditions for actions in places where those actions realistically couldn't appear if delete effects were included. Hence, causal links and delete effects encode a large amount of the search progress to reach a certain node, and by ignoring them within a heuristic, that heuristic is essentially being calculated for a significantly broader partial plan, one that might be similar to going back many layers of depth in the search tree. In any other planning domain, running a heuristic like this would be considered absurd, due to the fact that it is sacrificing large amounts of already obtained search progress that took a lot of effort to compute, in order to save computation time in further expansion of the search tree.\\


We present new informed and admissible heuristics which take into account these often ignored components of a partial-plan node. It has been shown by~\cite{ACloser Look at Causal Links: Complexity Results for Delete-Relaxation in Partial Order Causal Link (POCL) Planning} that to run a delete-relaxed heuristic which respects current causal links, delete effects, and ordering constraints, the heuristic will be NP-complete. However, as established previously, each POCL node can represent up to a factorial amount of action sequences, and so it is very possible that having a much more informed heuristic will unlock much of these benefits to partial-order planning that previous heuristics couldn't. This could mean that the trade-off of an NP-complete heuristic is worthwhile given the benefits to the search process. This is particularly the case in the question of satisfiability in planning: whether a valid plan exists to reach a set of goals with the given actions and initial state. State-based planners can often run forever when presented with infeasible planning problems, as their small amount of node information and efficient but less informed heuristics can get stuck with a search tree that grows faster than infeasible branches can be pruned (citation needed). We propose that an informed POCL heuristic that takes into account all details of the much more complex structure of a POCL node could determine infeasibility for factorial numbers of action sequences in a single NP-complete calculation, possibly allowing it to prune branches faster than the search tree can grow in cases where state-based planning cannot, providing a benefit for determining infeasibility in planning.
