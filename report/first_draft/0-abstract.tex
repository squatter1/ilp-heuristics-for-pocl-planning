\chapter*{Abstract}

Partial Order Causal Link (POCL) planning uses partial plans as search nodes to maintain a principle of least commitment, and to allow each node to represent up to a factorial number of action sequences. POCL nodes also store constraints on these possibilities using causal links, which provide complex plan information by committing to causal relationships between actions. These information-dense nodes provide a notional advantage for solving plan existence, as pruning a single infeasible POCL node is equivalent to pruning up to a factorial number of classical state-based search nodes. Yet current state-of-the-art POCL heuristics fail to capitalise on this, ignoring most of the information within search nodes in order to create heuristics that run in polynomial time. Progress in search is represented by the content of search nodes, and erasing this current progress to achieve further progress is considered inconceivable in other planning domains, yet it is the norm in POCL planning. By contrast, we propose to maintain this important information. We introduce new heuristics built with integer programming models which accurately translate classical delete-relaxation heuristics to POCL planning by maintaining search node information. This significantly reduces the search space, at the cost of slower calculation due to these heuristics being NP-hard to compute. (TODO: update end of abstract when we have results)
