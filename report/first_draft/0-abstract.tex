\chapter*{Abstract}

Partial Order Causal Link (POCL) planning uses partial ordering on actions to maintain a principle of least commitment, allowing for a single search node to represent an exponential number of action sequences. This means that pruning an infeasible branch in POCL planning can complete as much work as pruning an exponential number of branches in classical planning, providing an advantage for solving plan existence. To capitalise on this advantage, heuristics must effectively utilise the information contained in a partial plan search node. However, current state of the art POCL planning heuristics do not consider much of the information within the partial plan they are calculated on, erasing many of the benefits of POCL planning. We introduce a new heuristic using an integer programming model which maintains all current partial plan information; including delete effects, orderings, and causal links; in its calculations, only applying delete relaxation to additional actions. This makes the heuristic more effective at solving plan existence, at the cost of slower calculation due to the heuristic being NP-hard to compute.
