\chapter*{Abstract}

Partial Order Causal Link (POCL) planning uses partial plans as search nodes to maintain a principle of least commitment, and to allow each node to represent up to a factorial number of action sequences. POCL nodes also store constraints on these possibilities using causal links, which provide complex plan information by committing to causal relationships between actions. These information dense nodes provide an advantage for solving plan existence, as pruning a single infeasible POCL node is equivalent to pruning up to a factorial number of classical state-based search nodes. Yet current state-of-the-art POCL heuristics fail to capitalise on this advantage, ignoring most of the information within these NP size search nodes in order to create heuristics that run in polynomial time. Progress in search is represented by the content of search nodes, and erasing this current progress to achieve further progress is considered inconceivable in other planning domains, yet it is the norm in POCL planning. We introduce new POCL heuristics built with integer programming models which maintain important partial plan information in their calculations. This significantly reduces the search space, at the cost of slower calculation due to these heuristics being NP-hard to compute.
